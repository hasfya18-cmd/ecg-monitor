📲 Registrasi Notifikasi Pasien

Daftarkan pasien untuk menerima peringatan aritmia otomatis melalui Telegram.
Pastikan pasien sudah mengirim /start ke bot @LOVECG_Bot terlebih dahulu.

❓ Cara Mendapatkan Chat ID Pasien

1. Minta pasien buka Telegram, cari bot @LOVECG_Bot
2. Klik Start atau kirim pesan /start
3. Kirim pesan apa saja ke bot (misal: "halo")
4. Buka link ini di browser:
https://api.telegram.org/bot<TOKEN>/getUpdates
5. Cari angka di "chat":{"id": XXXXXXX} — itu Chat ID-nya

✅ Pasien Terdaftar Notifikasi Telegram

Pasien berikut akan menerima peringatan otomatis saat sistem mendeteksi aritmia pada rekaman EKG mereka.

Belum ada pasien terdaftar. Gunakan form di atas untuk mendaftarkan.
